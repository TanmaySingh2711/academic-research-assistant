# Academic Research Assistant

A fully local RAG app: upload research paper PDFs and ask questions about them.
Answers are generated by a local LLM (Ollama) using only the retrieved chunks, with sources (filename + page).

**Status: Work in progress**

## Tech Stack

- Python 3.12
- pdfplumber (PDF text extraction)
- sentence-transformers (`all-MiniLM-L6-v2` embeddings)
- faiss-cpu (vector search)
- Ollama + `llama3.2:3b` (local LLM)
- Flask (web dashboard)

## Setup

1. Create and activate a virtual environment (Windows):
   ```
   py -3.12 -m venv venv
   venv\Scripts\activate
   ```
2. Install requirements:
   ```
   pip install -r requirements.txt
   ```
3. Install Ollama from https://ollama.com/download
4. Pull the model:
   ```
   ollama pull llama3.2:3b
   ```
