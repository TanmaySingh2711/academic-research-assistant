{{ icon('flow', 14) }} How it works

From an empty folder to answers with sources

Three flowcharts: how the project was built, what happens inside when you use it, and what you can do on the dashboard.

The project was built in 12 small steps. Each step added one part of the RAG pipeline and was tested before the next one started.

{{ icon('flag', 16) }} Empty folder
{{ arrow() }}
Phase 1: Foundation
{{ node("Project setup", "Folders, a Python 3.12 virtual environment, the libraries, and Ollama with the llama3.2:3b model.", 1, "requirements.txt") }} {{ arrow() }} {{ node("Document loading", "Read every PDF page by page with pdfplumber, remove headers, page numbers and the reference list, and read scanned pages with OCR.", 2, "src/loader.py") }} {{ arrow() }} {{ node("Chunking", "Split each page into chunks of whole sentences, about 100 words, sharing the last sentence with the next chunk, so no idea is cut in half.", 3, "src/chunker.py") }} {{ arrow() }}
Phase 2: Search
{{ node("Embeddings", "Turn every chunk into 384 numbers that describe its meaning, with the all-MiniLM-L6-v2 model.", 4, "src/embedder.py") }} {{ arrow() }} {{ node("Vector database", "Store the vectors in a FAISS index and save it to disk next to the chunk text.", 5, "src/vector_store.py") }} {{ arrow() }} {{ node("Retrieval", "Search by meaning (FAISS) and by exact words (BM25), then let a re-ranker pick the K chunks that answer best.", 6, "src/retriever.py") }} {{ arrow() }}
Phase 3: Answering
{{ node("Prompt construction", "Give the model clear rules, the earlier questions of the chat, the numbered chunks as sources, and the question.", 7, "src/prompt_builder.py") }} {{ arrow() }} {{ node("Generation", "llama3.2:3b writes the answer through Ollama, word by word, with a low temperature (0.1) so it stays factual.", 8, "src/generator.py") }} {{ arrow() }}
Phase 4: Product
{{ node("Flask backend", "JSON routes to upload papers, build the index, ask questions and read the chat history.", 9, "app.py") }} {{ arrow() }} {{ node("Dashboard", "These pages, written in plain HTML, CSS and JavaScript, so they also work without internet.", 10, "templates/, static/") }} {{ arrow() }} {{ node("Testing and release", "pytest tests, browser tests, README, one-click setup scripts and CI checks on Windows, macOS and Linux.", 11, "tests/, .github/") }} {{ arrow() }}
Phase 5: Quality
{{ node("Evaluation", "68 questions with known pages measure how often the right chunk is found and the answer is right. Every change above was kept only if these numbers improved.", 12, "evaluation/") }} {{ arrow() }}

Build index

When you click Build index

Runs after you add papers. Only new or changed papers are read. Route: POST /process

{{ node("PDFs in data/", "The papers you uploaded.", "A1") }} {{ arrow() }} {{ node("Extract text per page", "pdfplumber reads each page. Headers, page numbers and references are removed, tables are written row by row, scans are read with OCR.", "A2") }} {{ arrow() }} {{ node("Split into chunks", "Whole sentences, about 100 words, never across two pages. Each chunk keeps its section heading.", "A3") }} {{ arrow() }} {{ node("Embed every chunk", "all-MiniLM-L6-v2 turns each chunk into 384 numbers.", "A4") }} {{ arrow() }} {{ node("Save the FAISS index", "New vectors are added to index/faiss.index, text and pages to index/chunks.json. The other papers are not touched.", "A5") }}
Ask

When you ask a question

Runs for every question. The first words appear after about 1 second. Route: POST /ask

{{ node("Your question", "Plus the paper you picked, K and the earlier questions of the chat. Only that paper is searched.", "B1") }} {{ arrow() }} {{ node("Two searches", "FAISS ranks the chunks by meaning, BM25 by the exact words. The two rankings are merged.", "B2") }} {{ arrow() }} {{ node("Re-rank", "A cross-encoder reads the question with each of the best 20 chunks and keeps the K that answer it (about 0.2 s).", "B3") }} {{ arrow() }} {{ node("Build the prompt", "Rules, the last two questions and answers, the chunks as [Source 1], [Source 2] and so on, then the question.", "B4") }} {{ arrow() }} {{ node("llama3.2:3b answers", "Word by word, straight to the screen. It may only use the sources; if they do not help, it says it could not find it.", "B5") }} {{ arrow() }} {{ node("Answer on screen", "With the sources, their pages and scores. The chat is saved in chats/.", "B6") }}
