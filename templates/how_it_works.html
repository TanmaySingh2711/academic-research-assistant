{{ icon('flow', 14) }} How it works

From an empty folder to answers with sources

Three flowcharts: how the project was built, what happens inside when you use it, and what you can do on the dashboard.

The project was built in 11 small steps. Each step added one part of the RAG pipeline and was tested before the next one started.

{{ icon('flag', 16) }} Empty folder
{{ arrow() }}
Phase 1: Foundation
{{ node("Project setup", "Folders, a Python 3.12 virtual environment, the libraries, and Ollama with the llama3.2:3b model.", 1, "requirements.txt") }} {{ arrow() }} {{ node("Document loading", "Read every PDF page by page with pdfplumber and keep the filename and page number with each page.", 2, "src/loader.py") }} {{ arrow() }} {{ node("Chunking", "Split each page into chunks of 100 words, with 20 words shared between neighbours, so no idea is cut in half.", 3, "src/chunker.py") }} {{ arrow() }}
Phase 2: Search
{{ node("Embeddings", "Turn every chunk into 384 numbers that describe its meaning, with the all-MiniLM-L6-v2 model.", 4, "src/embedder.py") }} {{ arrow() }} {{ node("Vector database", "Store the vectors in a FAISS index and save it to disk next to the chunk text.", 5, "src/vector_store.py") }} {{ arrow() }} {{ node("Retrieval", "Turn the question into numbers the same way and find the K chunks with the closest meaning.", 6, "src/retriever.py") }} {{ arrow() }}
Phase 3: Answering
{{ node("Prompt construction", "Give the model clear rules, the numbered chunks as sources, and the question.", 7, "src/prompt_builder.py") }} {{ arrow() }} {{ node("Generation", "llama3.2:3b writes the answer through Ollama, with a low temperature (0.1) so it stays factual.", 8, "src/generator.py") }} {{ arrow() }}
Phase 4: Product
{{ node("Flask backend", "JSON routes to upload papers, build the index, ask questions and read the chat history.", 9, "app.py") }} {{ arrow() }} {{ node("Dashboard", "These pages, written in plain HTML, CSS and JavaScript, so they also work without internet.", 10, "templates/, static/") }} {{ arrow() }} {{ node("Testing and release", "Test scripts, README, one-click setup scripts and CI checks on Windows, macOS and Linux.", 11, "tests/, .github/") }} {{ arrow() }}
{{ icon('check', 16) }} Working local RAG assistant

Three programs talk to each other, all on your own computer (127.0.0.1). Then two pipelines do the real work.
