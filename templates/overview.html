What this project is

A RAG assistant: Retrieval Augmented Generation. Before the model writes anything, the app finds the few paragraphs of your papers that match the question and gives only those to the model. That keeps the answer tied to real text you can check.

{{ icon('quote', 20) }}

Answers from your papers only

The model is told to use only the retrieved text. If the papers do not cover a question, it says so.

{{ icon('book', 20) }}

Every answer shows its page

How to use it

Four steps, all on the Assistant page.

1

Upload

Click the clip button or drop PDFs on the page.

2

Build index

The app reads and indexes the papers. About 15 seconds for 3 papers.

3

Ask

Pick one paper or all papers, type a question and press Enter.

4

Check

Open the sources under the answer to read the exact text.
